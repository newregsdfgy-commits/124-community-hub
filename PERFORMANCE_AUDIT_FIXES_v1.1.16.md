# 124 Community Hub v1.1.16 — Performance Stability / Regression Audit

**Дата:** 2026-11-02  
**Исходная версия:** `v1.1.15-max-performance-test` (`Hub.lua`)  
**Исправленная версия:** `v1.1.16-perf-stability-test`  
**Статус:** исходник обновлён в отдельной ветке; **реальных испытаний в Roblox, Delta и Xeno не проводилось**. `main` и v1.1.15 не затронуты.

## Какие замечания v1.1.15 исправлены

| Проблема | Изменение | Компромиссы |
|---|---|---|
| AUTO колеблется при 44/54 FPS | Переход в ECO только после 2 последовательных низких измерений и не раньше 2 секунд. Обратный переход — после 5 высоких измерений и не раньше 15 секунд с предыдущей смены | AUTO реагирует на краткие одиночные фризы менее резко; для ручного ECO задержки нет |
| Резкое создание и удаление ESP при сменах AUTO | Частота смен режима ограничена; выбор игроков упорядочен одинаково для Highlight/Labels и Box/Skeleton | При пересечении дистанций соседними игроками замены возможны |
| Box/Skeleton выбирает произвольные цели | Использует заранее отсортированный по квадрату дистанции список ближайших игроков; стабильный tie-break по UserId | Видимых объектов не больше бюджетов ECO/BALANCED/QUALITY |
| Box/Skeleton обходит игроков после достижения лимита | Цикл прекращается до новых чтений частей тела после выполнения лимита | Пропуск неподходящих/невидимых игроков продолжается до лимита |
| Повторные аллокации в ESP | Пул таблиц кандидатов переиспользуется, квадраты дистанций сравниваются без квадратного корня, дальность вычисляется раз за скан. Ссылки на выбывших игроков очищаются | Для хранения пула используется немного долгоживущей памяти |
| Анализ логов постоянно работает | Функция `sessionDiagnostics` выключена по умолчанию и при автозагрузке. Подписка LogService.MessageOut открывается только по переключателю MISC и отключается при OFF/Unload/Safety Stop | До включения диагностических логов события не записываются |
| Нет диагностики микрофризов | Кольцевой буфер 240 кадров, O(1) операция на кадр. В MISC отображаются оценка 1%-low (по p99 времени кадра), p99 мс, наибольший кадр, число задержек >=50 мс | Это оценка короткого окна, не замена системного профилировщика. При скрытом меню сортировка кадров не выполняется |
| Слишком много новых локальных переменных для большого Luau-файла | Новые счётчики, пул и ключевые слова размещены внутри существующих таблиц состояния. Количество строк объявления `local` верхнего синтаксического отступа не увеличилось (231 → 231) | Полноценный Luau compiler-check ещё необходим |

## Не изменялось

- AIM: поиск цели, прицеливание, плавность, строгий список зарегистрированных Tool и Visible Check.
- Recoil, Camera FOV, FullBright, Anti-Aim, Bunny Hop и Chat.
- FPS Booster: режимы, queue, сохранение и возврат графических свойств.
- UI-оформление ESP, шрифт, тонкие линии, настройки расстояния.
- Safe Stop и обработка существующих профилей.

**Важные сознательные компромиссы:** в ECO поиск AIM происходит с интервалом 0.24 с вместо 0.12 с в BALANCED; так сохраняется низкая нагрузка. RenderStep-подписки выключенных модулей остаются привязанными, но быстро выходят и не выполняют тяжёлых операций. Эти участки не менялись, чтобы не создавать новые регрессии.

## Статический контроль

- Проведено **60/60 целевых статических проверок** GitHub-исходника, без выявленных несоответствий.
- Отдельная лексическая проверка скобок, строк, комментариев и блоков `function`, `if`, `for`, `while`, `repeat`, `end`, `until` не выявила несогласованной структуры.
- Сверены фрагменты AIM, Recoil, Bunny Hop, Chat, Booster и внешнего вида ESP с v1.1.15.
- Смоделированы постоянная просадка, единичный просадочный кадр, дрожание FPS, восстановление производительности и сортировка ближайших игроков. В выбранных входных данных модель переключений дала ожидаемые переходы.
- **Это не полноценная компиляция Luau, не тест исполнения и не измерение FPS.** Причина всех фризов самой Roblox-игры по исходнику Hub однозначно не устанавливается.

## Рекомендуемая матрица тестов в Roblox

1. Холодный запуск, повторный запуск, Unload, Safety Stop и перезаход с прежним CUSTOM; проверить отсутствие дублирующегося GUI.
2. Простой без ESP и без Booster: сравнить базовую игру без Hub, v1.1.15 и v1.1.16 в одном месте.
3. Активировать ESP + Box + Skeleton: проверить, что остаются ближайшие игроки, при повороте камеры нет «замороженных» рамок, после респавна старые рамки исчезают.
4. Переключить вручную AUTO/ECO/QUALITY и наблюдать 30–60 секунд за изменениями FPS при росте числа игроков.
5. MISC → «Проверка микрофризов»: измерить 1%-low, p99, Max, количество кадров >=50 мс; закрыть окно и сравнить загрузку.
6. MISC → «Анализ логов»: проверить состояние OFF, затем ON/OFF, отсутствие ошибок и после выгрузки.
7. Проверить AIM с разрешённым Tool, Recoil при стрельбе, Bunny Hop, Camera FOV и полный откат FPS Booster.
8. Повторить отдельно на Android Delta и ПК Xeno. Разница может зависеть от загрузки сервера, качества сети и графических настроек.
