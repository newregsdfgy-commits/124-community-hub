**Дата:** 2026-11-02

## Патчи по A-01 — A-15

| ID | Итог | Реализация / пределы |
|---|---|---|
| A-01 | **Исправлено** | Повторный запуск проверяет успешность cleanup и recovery прежнего экземпляра. При ошибке или остаточном cleanup новый экземпляр **не запускается**. Новый cleanup возвращает `true` после завершения. Старые версии с `nil` при успехе поддержаны проверкой очистки env. |
| A-02 | **Исправлен аварийный сценарий** | `setBooster` обрабатывает ошибки при подготовке Lighting/Terrain и ошибки фонового обхода сцены через `pcall`. При сбое переводит Booster в OFF и пытается запустить восстановление. |
| A-03 | **Исправлено** | Автоматический поиск «возможно публичного» custom TextChannel удалён. Без стандартного `RBXGeneral` отправка отключена с диагностикой. |
| A-04 | **Исправлено** | Для `RBXGeneral` проверяется собственный `TextSource.UserId` и `TextSource.CanSend`. |
| A-05 | **Безопасное ограничение** | `PlatformIntegratedChat` нельзя прочитать из обычного LocalScript (`RobloxScriptSecurity`). По возвращаемому пустому/неподдерживаемому результату SendAsync показывается предупреждение использовать штатный чат. Ни одно системное ограничение не обходится. |
| A-06 | **Исправлена диагностика** | `Success` назван «локальный статус отправителя»; доставка получателям не утверждается. |
| A-07 | **Исправлено** | Введены отдельные `timerStatus` и `sendStatus`; READY больше не затирает статус отправки. |
| A-08 | **Ограничение движка** | Bunny Hop использует прыжки по земле и ограниченный `WalkSpeed`, а не пользовательский физический контроллер импульса. Обозначено без обещаний серверного ускорения. |
| A-09 | **Исправлено при возврате к базовой скорости** | При внешней смене WalkSpeed BHOP приостанавливается, а если игра вернула исходный WalkSpeed — возобновляет множитель без вмешательства в текущий спринт/стан. Если игра установила новый устойчивый базовый WalkSpeed, требуется повторное включение. |
| A-10 | **Исправлено** | У AIM set-таблица разрешённых имён Tool кэшируется и перестраивается только при изменении `state.aimWeaponNames`; больше нет конкатенации списка каждый кадр. |
| A-11 | **Исправлен небезопасный default** | Строгая проверка зарегистрированных Tool теперь ON по умолчанию и включается при автозагрузке старых профилей. Для использования AIM нужно выбрать оружие и нажать «Запомнить оружие в руках». Допускается ручное отключение строгого режима. Скрипт не угадывает вооружение игры. |
| A-12 | **Снижен риск** | Проверка временного бюджета в Booster, очереди и восстановлении перенесена с 16 объектов на каждые 4. Полной гарантии постоянных FPS/RAM без теста в игре нет. |
| A-13 | **Исправлено** | Recovery использует exponential backoff (2–120 сек) и ограниченную диагностику, вместо непрерывного повторного сканирования на каждом цикле. |
| A-14 | **Честное ограничение** | Отправка только ручная. Прервать уже начатый yielding `SendAsync` при OFF технически нельзя; UI поясняет это, но параллельные повторы не допускаются. |
| A-15 | **Обозначен предел** | Скорость и доступность API зависят от сервера/игры/executor. Статические проверки не заменяют исполнение на ПК или Android. |

## Дополнительное исправление

Подписанные состояния мобильного AIM и диагностика отражают, что Tool может быть экипирован, но не зарегистрирован как оружие (`NO GUN`).

## Статическая проверка

- С GitHub извлечён полный `Hub.lua` v1.1.14 и база v1.1.13.
- Выполнены 58 тематических проверок и 5 дополнительных проверок ручной отправки/таймера. Одна первоначальная проверка дала ложное срабатывание на комментарии `SendAsync`; уточнённая проверка подтверждает отсутствие **вызова** отправки в таймере.
- Проверка структурных скобок, строк, комментариев, `function/if/for/while/repeat/end/until` — без найденных ошибок.
- Подтверждено, что главные функции AIM Frame, Recoil и ESP не переписаны, а `main` всё ещё на v1.1.8.
- Компилятора Luau в доступной среде нет. Стабильность во время исполнения **не проверена**.

## Тест-матрица перед переносом в main

1. Холодный запуск v1.1.14 после v1.1.13 и горячий запуск 3 раза. Проверить число GUI, активных обработчиков и восстановление графики.
2. AIM без Tool, с незарегистрированным Tool, после регистрации оружия, после его снятия и респавна. Проверить, что приятная пользователю плавность сохранилась.
3. ESP Box/Skeleton/Tracers при 10/80/150/200 м на Android и ПК, FPS и читаемость.
4. FPS Booster BALANCED/WHITE/ULTRA с замером FPS/RAM до, во время и после; выключение, полная выгрузка и Safety Stop.
5. Переход на карту со StreamingEnabled, множественные подгрузки и переполнение очереди.
6. Bunny Hop при ходьбе, в воздухе, на стуле, после смерти, в процессе спринта и после возвращения к базовой скорости.
7. Chat Timer через 5/10/120 секунд: READY без отправки; отдельная ручная кнопка, проверка CanSend, отсутствия канала, ограничения интервала и доставки со второго клиента.
8. Переключение профилей LEGIT/RAGE/CUSTOM и проверка сохранения chatMessage/interval и зарегистрированных Tool.
9. Переход в риск-предупреждение при BHOP/Booster/Chat Timer; выключение всех систем и проверка отката.
10. Ошибки графических свойств на контролируемой тестовой карте: не оставлять Booster зависшим ON, не запускать второй Hub при неполной cleanup/recovery.

## Решение о релизе

**Не переносить v1.1.14 в main до реального smoke-test в Roblox.** По статике патч закрывает определённые дефекты, но нельзя правдиво утверждать, что каждое поведение runtime подтверждено.
