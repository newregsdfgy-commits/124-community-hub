# 124 Visuals v1.4.0 — исходная модульная сборка

`src/*.lua` — 12 логических модулей исходного кода, **не отдельные require(ModuleScript)**. Исходная программа содержит разделяемые `local` переменные и closures; поэтому временно используется сборка с общей лексической областью, обеспечивающая совместимость со старым исполнителем.

Сборка: `python3 tools/build_visuals.py --write` генерирует `Hub.lua` и `Visuals.lua` **байт-в-байт одинаковыми**, через временные файлы и атомарную замену. Проверка: `python3 tools/build_visuals.py --check`. Редактировать вручную только `src/` и генерировать оба entrypoint; ручной патч одного `Hub.lua` приведёт к CI fail.

Порядок:
- 00: конфигурация, boot preflight
- 01: Key System 2.0 (локальный UX)
- 02: состояние и сервисы
- 03: ESP 2.0 / отслеживание персонажей
- 04: графика и FPS Booster
- 05: Weapons 2.0 / отдача
- 05b: Player FX — локальные частицы, подсветка тела, Fog, rain overlay, цветокоррекция
- 06: создание GUI и runtime helpers
- 07: ESP 2D overlays
- 08: меню и элементы управления
- 09: Misc, Weapons UI, диагностика
- 10: запуск, RenderStep, cleanup

`Start.lua` остаётся отдельным защищённым загрузчиком: конкретная версия/ветка, mutex повторного входа, token-owned boot phase, fail-closed при ошибке и требование завершённой выгрузки старого экземпляра.

Клиентский ключ и лимит попыток не являются серверной авторизацией: для реальной проверки должен существовать доверенный сервер, который принимает решение и не отдаёт ключ клиенту. Никакой сервер здесь не развёрнут.

Проверки в CI: детерминированность сборки, static release + ESP/Key/lifecycle regression, Luau parse/compile. Проверка действий в реальной игре и UX Android необходима отдельно.

## v1.3.1 — корректировки аудита

- Key: подтверждение события сохраняется отдельно от `BindableEvent:Wait()`, чтобы уничтожение экрана до ожидания не зависало; пустая дублирующая отправка Android не затирает сообщение о неверном ключе.
- ESP: локальный респавн скрывает живые Billboard/Highlight/Tracer вместо массового уничтожения и нового выделения; срочная очередь не дублирует свежий полный скан.
- ESP: при выключенных Tracer и Box покадровое измерение CFrame не производится.
- `tests/build-131-runtime-audit.py` извлекает реальный обработчик ключа и реальную очередь ESP для проверки в Luau, в дополнение к статическим регрессионным проверкам.
