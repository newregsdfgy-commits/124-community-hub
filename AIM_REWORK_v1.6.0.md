# AIM v1.6.0 — scoped regression fixes

Base: `v1.5.9-esp-independent-range-controls-test`.
Scope: camera replacement, invalid prediction data, deterministic equal-score selection.

## Changes

- `src/04_lighting_and_booster.lua`: observe CurrentCamera before input/menu early returns. On identity change (including nil), clear target, scan deadline and LOS state through the existing reset routine. Reacquire using the current camera on the next eligible frame. Input flags, settings, weapon checks and smoothing are preserved.
- Prediction rejects nonnumeric, negative or nonfinite time, nonfinite velocity components, overflowed displacement and nonfinite output. Invalid velocity reads return the original target position. Existing displacement cap is preserved; no invalid vector is generated by prediction from a finite position.
- Equal screen-space scores use ascending UserId in both the no-LOS minimum search and LOS candidate sort. Target Lock retains its existing priority.
- Version/launcher point to v1.6.0 and its test branch. Both entrypoints rebuilt using the existing Python builder.
- Release verification compares source/bundle bytes directly, fixing Windows newline normalization mismatch.

## Validation

- Official Luau 0.747: Hub.lua, Visuals.lua, Start.lua compiled successfully with optimization level 2.
- Extracted production functions run in Luau: camera replacement, unchanged camera, nil camera, restoration, disabled AIM, valid/disabled prediction, NaN/infinities/negative/nonnumeric time, invalid velocity, overflow, throwing velocity access, displacement cap and deterministic ranking. Roblox API is mocked; these are not in-game tests.
- Current v1.5.9 CI Node regression selection: 166 passed, 0 failed.
- Python build check: both bundles identical to source fragments. Release integrity: 91/91 passed.
- All historical Node tests: 250/310 passed, 60 failed. Unmodified baseline: 246/310 passed, 64 failed. No new failing test names. Historical suites contain obsolete version/implementation assertions; the four removed exact old-AIM hash requirements are superseded by production behavior tests. Remaining historical failures are not reported as green.
- No Roblox/executor/Android live test was performed. FPS improvement is not claimed.

`.github/workflows/v160-aim-ci.yml` preserves the previous CI suite and adds the new Luau regression harness.
