## Исправления по замечаниям полного аудита
| Пункт | Решение | Ограничение |
|---|---|---|
| F-01 Chat | Неподтверждаемая автоотправка **убрана**. Есть собственный TextBox, ручная кнопка отправки и Chat Timer, который не отправляет ничего сам. | Roblox TextChannel:SendAsync допускает доставку сообщений, отправленных пользователем; даже ручная отправка из GUI требует проверки вторым аккаунтом. |
| F-02 Risk Warning | Добавлены Bunny Hop, Chat Timer, Booster, Camera FOV в список; кнопка предупреждения выключает их и запускает восстановление. | Крупный графический откат может занять время. |
| F-03 Booster unload | Откат большого числа графических объектов разделён на части с task.wait по бюджету CPU. То же для повторного recovery. | Полный откат по-прежнему проходит по сохранённым свойствам. |
| F-04 Bunny Hop semantics | Явно отделены «задержка прыжков» и «множитель WalkSpeed»; не заявляется физическое накопление скорости. | Это не полноценный momentum-based bunny hop. |
| F-05 WalkSpeed | Если сама игра меняет скорость, BHOP прекращает вмешиваться; состояние PAUSED видно в диагностике. Запись WalkSpeed пропускается, если значение уже совпадает. | Для повторного применения после внешнего изменения нужно выключить и включить BHOP. |
| F-06 Chat cancellation | Нет автоматического фонового SendAsync; ручная отправка защищена от параллельных запросов и использует токен после ответа. | У Roblox нет отмены уже начатого yielding SendAsync. |
| F-07 Channel | При отсутствии RBXGeneral выбирается только единственный доступный публичный TextChannel с собственным TextSource.CanSend. Не выбираются системные, team и whisper каналы. | Если доступно несколько публичных каналов или нет TextChatService, ручную отправку блокирует диагностика. |
| F-08 Streaming | Повторные проходы после новых переполнений разрешены, ограничены cooldown 12 сек и максимум 3 ошибками. | Большой уровень может долго обрабатываться. |
| F-09 Booster performance | Сохранены лимиты CPU времени, батчи и ограниченная очередь из v1.1.9; распределённый cleanup снижает риск фриза на выключении. | Реальные FPS/RAM пока не измерены; универсального способа мгновенно перекрасить всю карту нет. |
| F-10 AIM Tool | Добавлен опциональный строгий список оружия. Нажатием кнопки игрок регистрирует реальный Tool по точному имени, без угаданных названий. Настройка сохраняется глобально. | По умолчанию режим выключен, чтобы не сломать существующее наведение до регистрации оружия. |
| F-11 Unicode | Лимит переименован в ChatMaxCodepoints — действительно считает UTF-8 кодовые точки, а не графемы. | Видимые составные emoji могут состоять из нескольких кодовых точек. |
| F-12 Profiles | chatMessage и chatInterval сохраняются отдельно от LEGIT/RAGE/CUSTOM; аналогично список разрешённых Tool. | Необходимо протестировать сохранение writefile на используемом executor. |

## Ручная тест-матрица
1. Открытие MISC, движение и переключение BHOP, скорость x1.0 и x2.0.
2. Проверить остановку при сидении, прыжке, респавне и внешнем изменении WalkSpeed.
3. Выключить BHOP: исходная скорость должна вернуться, если игра её не переопределила.
4. Chat Timer ON: через 5–120 сек появляется READY, **ничего не отправляется автоматически**.
5. Ручной Send: написать текст, нажать кнопку; проверить статус и доставку на втором клиенте, не считать счётчик доказательством.
6. Проверить отсутствие RBXGeneral и custom channel, ошибки privacy и floodcheck.
7. Переключить LEGIT/RAGE/CUSTOM, перезапустить и проверить сохранение chatMessage, интервала и списка Tool.
8. AIM без оружия; с обычным Tool; регистрация реального Tool; строгий режим ON/OFF.
9. Risk Warning: кнопка выключает все заявленные активные функции.
10. FPS Booster WHITE/ULTRA и многократная подгрузка StreamingEnabled; FPS/RAM до, во время и после; Unload и Safety Stop.
11. Проверить прежние ESP/Recoil/AIM/FullBright и восстановление освещения.
